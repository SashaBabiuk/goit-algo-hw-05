# Домашнє завдання №5: алгоритми пошуку

## Опис

У роботі порівняно швидкість трьох алгоритмів пошуку підрядка:

- Боєра—Мура (правило поганого символу);
- Кнута—Морріса—Пратта;
- Рабіна—Карпа.

`search_algorithms.py` містить реалізації алгоритмів. `benchmark.py` зчитує обидві статті, перевіряє результат кожного алгоритму за допомогою `str.find`, вимірює час та визначає переможців.

## Методика

Для кожної статті обрано один наявний та один вигаданий підрядок.

| Текст | Наявний підрядок | Вигаданий підрядок |
|---|---|---|
| Стаття 1 | `алгоритми та структури даних` | `квантовий гіперпростір` |
| Стаття 2 | `рекомендаційної системи` | `квантовий гіперпростір` |

Заміри виконано модулем `timeit`: 5 повторів по 100 запусків. У таблиці наведено найкращий середній час одного виклику. До заміру входить повний виклик функції, включно з побудовою службових таблиць алгоритму. Результати можуть дещо відрізнятися на іншому комп’ютері.

## Результати

Час одного пошуку, мкс:

| Текст | Підрядок | Боєра—Мура | Кнута—Морріса—Пратта | Рабіна—Карпа | Найшвидший |
|---|---|---:|---:|---:|---|
| Стаття 1 | наявний | 17.39 | 80.29 | 189.16 | Боєра—Мура |
| Стаття 1 | вигаданий | 262.58 | 1543.42 | 4084.76 | Боєра—Мура |
| Стаття 2 | наявний | 5.57 | 12.59 | 23.15 | Боєра—Мура |
| Стаття 2 | вигаданий | 365.87 | 2264.94 | 5977.41 | Боєра—Мура |

## Висновки

- **Стаття 1:** найшвидшим для обох типів підрядка став алгоритм Боєра—Мура.
- **Стаття 2:** найшвидшим для обох типів підрядка також став алгоритм Боєра—Мура.
- **Загалом:** на цих текстах і вибраних підрядках найкращий результат показав алгоритм Боєра—Мура. Він порівнює шаблон справа наліво і завдяки таблиці останніх входжень часто пропускає кілька позицій за один крок. Особливо помітна перевага під час пошуку відсутнього підрядка, коли потрібно переглянути весь текст.

Ці висновки стосуються саме даної реалізації, текстів і підрядків: для інших вхідних даних співвідношення швидкості може змінитися.

## Запуск

Потрібен Python 3.9 або новіший. Сторонні бібліотеки не потрібні.

```bash
python3 benchmark.py
```

Запуск тестів:

```bash
python3 -m unittest -v
```
